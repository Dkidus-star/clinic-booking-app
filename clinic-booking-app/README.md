# Addis Clinic Booking App

A fully responsive React web application designed to provide clinic booking experience. Built with performance and modern UI/UX principles in mind, this application features physics-based animations, fluid typography that scales across ultra-wide monitors, and persistent local data management.

## React Mini-Project & Capstone Kickoff"

The primary expectations successfully met include:

- **Component-Based Architecture:** Building modular, reusable React components (such as a global Layout and Navbar) to maintain a clean and scalable codebase.
- **Client-Side Routing:** Implementing `react-router-dom` for seamless, single-page navigation between the Home, Doctor Directory, User Profiles, Authentication, and Dashboard views.
- **State Management & Persistence:** Utilizing React hooks (`useState`, `useEffect`) alongside browser `localStorage` to create a mock database for user authentication, session management, and appointment booking/cancellation.
- **Modern UI/UX Implementation:** Elevating standard CSS with fluid typography, scroll-triggered physics animations (via Framer Motion), and accessible global toast notifications (via React Hot Toast).
- **Responsive, Full-Screen Layouts:** Ensuring the application is fully usable and visually proportional across all screen sizes—from mobile devices to 4K displays—by overriding restrictive default layout wrappers.

## ✨ Key Features

- **User Authentication:** Secure signup and login flows with session persistence.
- **Dynamic Doctor Directory:** Browse and filter healthcare providers by medical specialty.
- **Appointment Management:** Users can seamlessly book, view, and cancel appointments in a dedicated dashboard.
- **Premium Animations:** Staggered list reveals, smooth page transitions, and interactive hover states.
- **Modern Notifications:** Global toast notifications replace intrusive browser alerts for a polished user experience.
